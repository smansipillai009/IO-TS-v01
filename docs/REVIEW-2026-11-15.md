# Review: backend + frontend uploads (15 Nov)

## Found and fixed
| # | Problem | Fix |
|---|---|---|
| 1 | `POST /api/investigations` always returned the one stored field (`coordinates_used: false`). The frontend only calls this, so the real pipeline was **not connected** | Live mode: POST runs the pipeline for the coordinates sent; GET returns the result in the agreed shape (`app/bridge.py`, `app/investigations.py`). Static mode kept for development |
| 2 | Taking the oldest N exposures gives N different wavelengths, so no pair is comparable and the difference view is always empty | Download a time-spread pool, read each frame's wavelength at the target, show the groups with the most epochs (`choose_frames`, `pool_size`) |
| 3 | Uploaded `irsa.py` lacked the TAP retry (IRSA returned 502/503) | Retry restored, alternating sync/async |
| 4 | No `error_code` on failures, so the page always said "Something went wrong" | `no_observations` / `download_failed` / `invalid_request` / `processing_failed` stored and returned |
| 5 | `max_frames` was not part of the request id (two different requests could collide) | Added to the id |
| 6 | `save-demo.mjs`: never checked the POST (polled `/api/investigations/undefined` for 5 min), dropped `difference_frames` (fallback demo would lose its difference images), broke on Windows paths | Rewritten |
| 7 | `.env` had name lookup and spectrum off though the backend now serves both | Turned on |

## Not fixed (needs a decision or real data)
- Frontend keeps `stretch` in the URL but never applies it. The backend supports `?stretch=` on product URLs; add a select if wanted.
- `WAVELENGTH_TOL_FRAC` / `PASS_GAP_DAYS` in the frontend are placeholders; the backend's groups override the first.
- fov 1 deg with 24 frames is rejected by the 150 MB transfer budget with a readable message; lower the options or raise `MAX_EST_MB`.

## Verified here vs not
- Run: 35 checks of pure logic (validation, ids, grouping, frame selection, alignment accuracy, stretch, bridge shape); full app wiring smoke test with stand-in modules; `node --check` on the script.
- NOT run (no network in my sandbox): FITS reading, reprojection, the FastAPI request path, `tests/test_api.py`, `tests/test_live_investigations.py`, the frontend build/typecheck, and anything against live IRSA.
